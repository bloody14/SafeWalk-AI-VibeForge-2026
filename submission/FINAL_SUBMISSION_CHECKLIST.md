# VibeForge Final Submission Checklist

## Product
- [ ] SafeWalk problem and target user clear.
- [ ] Route search/demo scenario works.
- [ ] Map or clearly labelled fallback route works.
- [ ] Fastest vs condition-aware comparison works where data permits.
- [ ] Lighting, reported incident, pedestrian activity and feedback data visibly labelled by source/status.
- [ ] AI explanation live or fallback clearly identified.
- [ ] Journey completion and feedback work.
- [ ] Feedback appears as local/unverified unless shared storage and verification truly exist.
- [ ] No guarantee-of-safety or unsupported crime prediction claim.

## Deployment/source
- [ ] Application builds and starts locally.
- [ ] Public URL opens and core flow tested, if deployment is claimed.
- [ ] Local demo still works.
- [ ] Source code and README included.
- [ ] Secrets are not in source, screenshots or repository.

## Evidence/rules
- [ ] Actual ChatGPT/Antigravity/Gemini/Graphify prompt history saved.
- [ ] Screenshots and recording saved with actual timestamps.
- [ ] Graphify evidence included if actually used.
- [ ] Earlier SafeWalk prototype disclosed.
- [ ] Pre-contest starter pack disclosed if asked.
- [ ] APIs, libraries, map tiles and datasets disclosed.
- [ ] Organiser approval evidence retained.

## Presentation
- [ ] Six-slide PPT completed and exported to PDF.
- [ ] Actual screenshots used.
- [ ] Demo rehearsed.
- [ ] Both team members can explain their roles and limitations.
- [ ] Live URL and local fallback ready.
